# Market Research and Marketing

Growth skills for Product & Marketing Managers — unified in one directory.

## Overview

Merged from two sources:
- **Marketing** (48 original skills)
- **PM Core** (69 skills from pm-skills)

Total: **109 skills**, 10 plugins, organized in 3 layers.

## Structure

```
growth/
├── marketing/          48 skills — content, SEO, ads, analytics, social
├── pm-execution/       16 skills — PRD, sprint, OKR, retro
├── pm-product-discovery/  13 skills — research, assumptions, experiments
├── pm-product-strategy/   12 skills — SWOT, canvas, vision, positioning
├── pm-market-research/     7 skills — personas, journey, segments
├── pm-go-to-market/        6 skills — positioning, channels, launch
├── pm-ai-shipping/         3 skills — review, delivery
├── pm-data-analytics/      3 skills — A/B test, cohort, SQL
├── pm-marketing-growth/    5 skills — campaigns, north-star, loops
└── pm-toolkit/             4 skills — PRD, grammar, privacy, resume
```
